# SequentialExecutor Example

The example is a SwiftUI macOS app for exploring the runtime behavior of `SequentialExecutor`.

![SequentialExecutor example app](SequentialExecutorExample.png)

## Run the App

1. Open [`SequentialExecutorExample.xcodeproj`](SequentialExecutorExample.xcodeproj) in Xcode.
2. Select the `SequentialExecutorExample` scheme and **My Mac** as the run destination.
3. Build and run the app.

The project uses the package from the repository root, so no additional dependency setup is required.

## What to Try

- Enable interval scheduling and change the next interval.
- Configure the next execution duration and success rate.
- Trigger an immediate execution or simulate a failure.
- Observe the applied runtime state and lifecycle event log.
- Open the in-app documentation page to visit the online API reference.

For complete API details, see the [SequentialExecutor documentation](https://swiftpackageindex.com/shensven/swift-sequential-executor/main/documentation/sequentialexecutor).
